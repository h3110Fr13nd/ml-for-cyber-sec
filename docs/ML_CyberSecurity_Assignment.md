# Assignment: Machine Learning-Based Intrusion Detection System

## Problem Statement

A mid-sized organization is facing increasing cyber threats such as unauthorized access, denial-of-service attacks, and abnormal network behavior. Traditional rule-based security systems are failing to detect new and evolving threats.

Design and implement a Machine Learning-based Intrusion Detection System (IDS) to classify network traffic as normal or malicious.
